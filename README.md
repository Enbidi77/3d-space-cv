# 3D Space Exploration Developer Portfolio & Interactive CV

> **"Explore the Universe of My Engineering Journey"**  
> An interactive 3D developer portfolio and interactive CV for **Nguyen Bao Duy**, Fullstack & Backend Software Engineer based in Can Tho / Ho Chi Minh City, Vietnam.

---

## 🌌 Overview

This project transforms a traditional professional curriculum vitae into an explorable 3D star system. Every planet, orbital station, and constellation represents a real-world chapter of Nguyen Bao Duy's engineering career:

- **Home Base:** System core, engineer identity, and professional summary.
- **Career Orbit:** Work experience stations at **Công ty TNHH Tỷ Xuân** (ERP & SQL Server systems) and **TPS Software** (distributed microservices & AWS/Azure CI/CD).
- **Technology Constellations:** 7 interactive skill clusters covering Java (Spring Boot), C# (ASP.NET Core), TypeScript/Next.js, SQL Server, PostgreSQL, AWS/Azure, and messaging architectures.
- **Project Worlds:** Four interactive planetary environments:
  1. *Comms-Nova:* Real-Time Enterprise Collaboration Monorepo (NestJS, Next.js 14, WebRTC, Redis, BullMQ).
  2. *Logistics-Prime:* Vehicle Rental Management Platform (Spring Boot / .NET Core, Angular, AWS Lambda, AWS SQS, PostgreSQL).
  3. *Aegis-Data-Cluster:* Broker Loan Matching & Ingestion Portal (ASP.NET Core, Elasticsearch, SQL Server, Dapper).
  4. *Forex-Chronos:* Forex Predictive Analytics & Real-Time Social Platform (Spring Boot, Vue.js/Next.js, Redis Pub/Sub, Docker, GitLab CI/CD).
- **Education Station:** Academic foundation at Can Tho University (Bachelor's in IT, 2019 – 2024).
- **Contact Beacon:** Subspace comm relay with copy-to-clipboard feedback, direct email/phone links, and downloadable CV document.

---

## 🛠 Tech Stack

- **Monorepo Architecture:** Turborepo, pnpm workspaces
- **Frontend Framework:** Next.js 15 (App Router, Server-Side Rendering & Static Generation), TypeScript
- **3D Graphics & WebGL:** Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`)
- **State Management:** Zustand
- **Styling & Design System:** Tailwind CSS, Glassmorphic UI primitives, Lucide React
- **Schema Validation:** Zod
- **Testing:** Vitest, React Testing Library

## 🚀 Quick Start

### Prerequisites
- Node.js `>= 20`
- pnpm `>= 9`

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/Enbidi77/3d-portfolio-cv.git
cd 3d-portfolio-cv

# Install monorepo dependencies
pnpm install

# Run the development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
